# Neurotech & EEG Signal Processing with MNE-Python

Este repositorio documenta mi proceso de aprendizaje y especialización en el área de la neurotecnología, con un enfoque específico en el procesamiento de señales electroencefalográficas (EEG) mediante la librería **MNE-Python**.

Como estudiante de 3.º de Inteligencia Artificial, mi objetivo es aplicar técnicas de **Machine Learning** y **Deep Learning** para la identificación de patrones neuronales en interfaces cerebro-computadora (**BCI**).

---

## 🎯 Objetivos del Proyecto

### 📂 Dominio de Manipulación de Datos
Carga y gestión de diversos formatos de señales biomédicas:

- `.edf`
- `.fif`
- `.set`

### 🧹 Preprocesamiento Avanzado
Implementación de técnicas de limpieza y filtrado:

- Filtros paso banda
- Filtros Notch
- ICA (*Independent Component Analysis*)

### 📊 Visualización y Análisis
Exploración y análisis de señales EEG mediante:

- Mapas topográficos
- Análisis de densidad de potencia espectral (PSD)

### 🤖 Integración con Inteligencia Artificial
Preparación y procesamiento de datos para modelos de:

- Clasificación de tareas motoras
- Interfaces cerebro-computadora (BCI)
